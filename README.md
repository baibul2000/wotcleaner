# 🎮 WOTCLEANER

**Управление HD / SD клиентами — Мир Танков и World of Tanks**

WOTCLEANER — небольшая утилита, предназначенная для удаления ненужных файлов HD- или SD-клиента игры Мир Танков (Lesta) и World of Tanks (Wargaming).

Программа помогает освободить место на диске, удаляя файлы неиспользуемого клиента без необходимости полной переустановки игры.

## ✨ Возможности

- 🟢 Удаление ненужных файлов HD-клиента.
- 🟢 Удаление ненужных файлов SD-клиента.
- 🟢 Поддержка лаунчера Lesta Games.
- 🟢 Поддержка Wargaming.
- 🟢 Удобный графический интерфейс.
- 🟢 Пошаговая инструкция перед началом работы.

## ⚙️ Как пользоваться

1. Запустите лаунчер Lesta Games или Wargaming.
2. Откройте настройки игры и выберите нужный клиент.
3. Выберите SD-клиент, если хотите удалить HD-клиент, или HD-клиент, если хотите удалить SD-клиент.
4. Дождитесь завершения загрузки выбранного клиента.
5. Закройте игру и запустите WOTCLEANER.
6. Следуйте инструкциям программы.

## ⚠️ Важная информация

- Для корректной работы оба клиента (HD и SD) должны быть установлены.
- Перед использованием рекомендуется закрыть игру и лаунчер.
- Не удаляйте файлы игры вручную.
- Перед выполнением операций рекомендуется создать резервную копию важных файлов.

## 🖥️ Поддерживаемые версии

- Мир Танков — Lesta Games.
- World of Tanks — Wargaming.
